# P03 — Моки API и слой данных сущностей
Цель: весь сценарий прототипа работает на моках MSW с сохранением в localStorage, а экраны получают данные через TanStack Query.

Сделать:
1. `apps/web/src/shared/api/mocks/fixtures`: 40 демо-мест внутри Садового кольца (все 4 типа, реалистичные названия и адреса, координаты внутри кольца, часы и чек; 5 мест без часов, 3 без чека). Демо-данные, без реальных отзывов и рейтингов.
2. Обработчики MSW (состояние в localStorage, задержки 300–800 мс):
   - `POST /me` — анонимный профиль; `GET /places/search?q=` — подсказки со 2-го символа, внутри кольца выше;
   - `POST /links/resolve {url}` — до 3 кандидатов за ~1,5 с, детерминированно по ссылке; ссылки с `private` или без пути → 0 кандидатов;
   - `GET/POST/DELETE /me/places`, `PATCH /me/places/:id` (заметка), повтор → 409 «уже в твоих местах»;
   - `POST /me/places/:id/visits` (не больше одного в день), `PATCH` ответа об ожиданиях;
   - `GET/PUT /me/shortlist` (≤ 5), `POST /me/shortlist/share` → token; `GET /s/:token`, `POST /s/:token/votes` (повтор из того же браузера заменяет голос);
   - `POST /reports` (не нашли место), `POST /events`.
3. `apiPost`, `apiPut`, `apiPatch`, `apiDelete` рядом с `apiGet` в `shared/api`.
4. Сегменты `api` и `model` сущностей: `entities/place` (поиск), `entities/saved-place` (мои места, CRUD, визиты), `entities/shortlist` (мой шорт-лист, share, страница друга, голоса), `entities/session` (анонимный профиль) — `queryOptions` и мутации со схемами из `@where-is-hype/core`.

Демо для эксперта (КТ-3, сценарий в деке; кликает сам эксперт):
- Две заготовленные ссылки, вынеси их константами в `shared/api/mocks/fixtures/demo-links.ts`: `https://www.instagram.com/reel/hype-coffee/` распознаётся (первый кандидат — кофейня, всего 2–3 кандидата с адресом и метро), `https://www.instagram.com/reel/unknown-place/` не распознаётся (0 кандидатов).
- Повторная вставка распознанной ссылки после сохранения даёт 409 «уже в твоих местах».
- Демо-данные подобраны так, что фильтр «Открыто в 19:00, чек до 1 500 ₽» по сохранённым местам даёт 3–5 мест, среди них хотя бы одно с «Часы не уточнены». В отчёте покажи, какие места и как это получается.
- Новый профиль начинается с пустых «Моих мест» (развилка «пустая карта»). Чтобы эксперт быстро дошёл до фильтра, на пустом экране P09 будет кнопка «Демо: добавить 8 мест»: сделай для неё `POST /demo/seed`, который добавляет 8 мест из фикстур (только при `VITE_API_MOCKS=true`).
- `VITE_API_MOCKS=true pnpm --filter web build` собирает статическую сборку, в которой моки работают (service worker MSW в `public`), чтобы прототип можно было выложить ссылкой.

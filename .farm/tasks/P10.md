# P10 — US4 Фильтр «на вечер»
US4 из `docs/product/mvp-scope.md`. Макеты: экраны 09–10 в `docs/design/zin/ScreensB.dc.html`, `hour-picker`, `price-picker` в `Components.dc.html`.

- `features/evening-filter`: «Открыто в» (Сейчас или час сегодня, прошедшие скрыты), тип, чек «до N ₽», «Рядом с метро, до 1 км»; состояние в query-параметрах URL, поэтому сохраняется при переходе в карточку и назад.
- Карта и список на `/` обновляются сразу, «Показать N из M», места без часов или чека помечены «не уточнено», а не скрыты.
- Пусто → экран 10: «Ничего не подошло», подсказки ослабить фильтр с числом, «Сбросить фильтры».
- Событие `filter_applied`.

Демо для эксперта: число найденных видно всегда («Показать N из M»); на пустом результате текст ровно «Ничего не подошло» и кнопка «Сбросить фильтры»; назад из карточки возвращает тот же фильтр.

Зона: `apps/web/src/features/evening-filter`, правки в `apps/web/src/pages/my-places` для подключения фильтра.

## Решения и наблюдения

- **Детерминированный поворот наклеек (`shared/ui/sticker`)**:
  - В `sticker-tilt.ts` реализована чистая функция `getStickerTilt(id, tilt)` по хешу строки (`STICKER_TILT_ANGLES = [-4, -3, -2, -1.5, 1.5, 2, 3, 4]` градусов в пределах ±4°).
  - По умолчанию `tilt = false` (`0deg` — в списках, шторках, чипах и заголовках наклейки стоят ровно по правилу «поворот только на карте»). При `tilt={true}` угол выбирается детерминированно по `id`, либо может быть передан явно числом.
- **Состояния и виды наклеек (`shared/ui/sticker`)**:
  - Типы: `coffee` (Кофе, горчичный `--color-st-coffee`), `cafe` (Кафе, мятный `--color-st-cafe`), `rest` (Ресторан, лавандовый `--color-st-rest`), `bar` (Бар, томатный `--color-st-bar`).
  - Размеры: `sm` (24 px), `md` (34 px), `lg` (38 px), `xl` (42 px).
  - Состояния (`state`):
    1. `default` — цветная заливка по типу, бумажный кант `--color-st-paper`, обводка `--color-st-ink` и жёсткая тень `0 2px 0 var(--color-st-ink)`.
    2. `selected` — поднята над картой (`scale(1.12)`), вокруг нарисован рукописный `MarkerOval` (на баре инвертируется в `ink`, т.к. сам бар уже томатный).
    3. `evening` (или флаг `inEvening={true}`) — красный флажок «в планах на вечер» в правом верхнем углу (на баре заливка флажка инвертируется в бумажный `#FFFDF8`).
    4. `visited` — приглушённая прозрачность (`opacity: 0.72`) и диагональный штрих `Strike` поверх кружка (на баре инвертирован в `ink` с бумажной подложкой).
    5. `unknown` — бумажный фон с пунктирной внутренней рамкой («Ещё не разглядели») для мест без распознанного типа.
  - Дополнительные маркеры карты в `shared/ui/sticker`:
    - `StickerCluster`: стопка из 3 кружков с моноширинным числом (`font-mono`). При `count > maxCount` (по умолчанию 40) показывает `40+` на нейтральной бумажной крышке.
    - `MyLocationDot`: пульсирующий маркер «Я здесь» (`14px` точка в бумажном канте + ореол `36px`).
    - `MetroStation`: три варианта по макету — `origin` (пилюля «М Чистые пруды» с кружком `М`), `map` (тихий текстовый ориентир `● М` на карте) и `badge` (значок `М`).
- **Доступность (`aria-label` / `aria-hidden`)**:
  - Функция `formatStickerAriaLabel` формирует русскоязычную подпись для скринридера из названия, типа, состояния (`выбрано` / `уже был` / `тип не указан`) и признака `в планах на вечер`. Если пиктограмма стоит рядом с видимым названием места, поддерживается `decorative={true}` (`aria-hidden="true"`).
  - Все рукописные SVG-элементы (`MarkerOval`, `Strike`, `ArrowHand`, `Tape`) в `shared/ui/decor` имеют `aria-hidden="true"` и `focusable="false"`.
- **Логотип (`shared/ui/logo`)**:
  - `LogoLockup`: заголовок «Где Хайп» (`Dela Gothic One`) + наклейка «?» с наклоном `-4deg` (без дублирования знака вопроса в тексте).
  - `LogoCompact`: компактный строчный логотип «Где Хайп?» с томатным «?» и опцией `pill={true}` для плашки поверх карты.
  - `LogoMark`: отдельная круглая наклейка «?».
- **Иконки приложения (`apps/web/public`)**:
  - Контур глифа `?` извлечён напрямую из шрифта `Dela Gothic One` (`@fontsource/dela-gothic-one`), поэтому SVG и PNG-иконки идентичны типографике логотипа и не зависят от системных шрифтов.
  - `favicon.svg` автоматически переключает внешнюю подложку с `#17140F` на `#FFFDF8` при `@media (prefers-color-scheme: dark)`.

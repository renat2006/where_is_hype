### Замечания

#### P2-1: `CandidateCard` — отсутствует проп `evidenceQuote` / «Почему нашлось»

**Файл**: `apps/web/src/entities/place/ui/candidate-card.tsx`
Автор описал в отчёте «плашку „Почему нашлось" с цитатой `evidenceQuote`», но в коде её нет. Тип `Candidate` в `@where-is-hype/core` не имеет поля `evidenceQuote` (только `place` + `confidence`), поэтому автор и не мог это реализовать. Это **не баг автора**, а недоработка модели данных — для экранов кандидатов понадобится расширение `Candidate` в core. Помечаю P2 (не блокирует приёмку) — нужно учесть при интеграции экрана добавления.

#### P2-2: `NoteView` — по умолчанию `handwritten={false}`, макет показывает рукописный текст

**Файл**: `apps/web/src/entities/saved-place/ui/note-view.tsx`, строка 27
Макет `Components.dc.html` отображает заметку шрифтом `f-hand` (Caveat, 26px). Компонент поддерживает `handwritten` проп, но по умолчанию он `false`. Это сделано осознанно (правило «один акцент на экран» — если заметка рядом с tape-декором, второй рукописный элемент был бы лишним). Допустимо: потребитель выставит `handwritten={true}` по месту.

#### P2-3: `PlaceRow` — нет пропа `selected` / `onSelect`

**Файл**: `apps/web/src/entities/place/ui/place-row.tsx`
Задача P06 упоминает поддержку `onSelect` и `selected`. Компонент поддерживает `onClick`, но нет явного `selected` состояния с визуальным выделением. Это не блокирует — `selected` понадобится при интеграции в экран «На вечер», а компонент расширяем. P2.

#### P2-4: `CandidateCard` — отчёт описывает `shadow-card`, в коде тени нет

**Файл**: `apps/web/src/entities/place/ui/candidate-card.tsx`
Автор в отчёте пишет «карточка с тенью `shadow-card`», но в коде тени нет — используется только `border-ink`. По правилу «рамки и тени по делу» это корректно: обводка `ink` уже даёт визуальное выделение, дополнительная тень избыточна. Расхождение отчёта и кода — P2 (отчёт неточен, код правильнее).

#### P2-5: `SourceVideo` — превью обложки/капшена не реализовано

**Файл**: `apps/web/src/entities/saved-place/ui/source-video.tsx`
Отчёт автора упоминает «превью обложки/капшена», но компонент рендерит только статичный SVG play-иконку. Макет тоже не показывает реальную обложку — только цветной прямоугольник. P2: если появится API для thumbnail, потребуется расширение.

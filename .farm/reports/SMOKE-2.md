## Решения и наблюдения

- Для значений до 1000 метров расстояние округляется до целых метров (`Math.round(meters)`): `0` → `«0 м»`, `450` → `«450 м»`, `999` → `«999 м»`.
- Если при округлении дробных метров значение достигает `1000` (например, `999.5`), используется километровый формат (`«1,0 км»`), чтобы избежать некорректного вывода `«1000 м»`.
- Для значений от 1000 метров возвращаются километры с одной цифрой после запятой через запятую (`(meters / 1000).toFixed(1).replace('.', ',') + ' км'`): `1000` → `«1,0 км»`, `1234` → `«1,2 км»`.
- Отрицательные числа, `NaN`, `Infinity` и `-Infinity` считаются невалидными физическими расстояниями — для них выбрасывается `RangeError`, чтобы ошибки в расчётах координат не маскировались в UI под `«0 м»`. Поведение зафиксировано и задокументировано в юнит-тесте.

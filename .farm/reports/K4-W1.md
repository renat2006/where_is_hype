## Решения и наблюдения

### 1. Выбор SDK: `@tma.js/sdk-react@3.0.23` vs `@telegram-apps/sdk-react@3.3.9`

Проверка в реестре npm (`npm view <pkg> version` / `time`):

- **`@tma.js/sdk-react` (`3.0.23`, март 2026) + `@tma.js/sdk` (`3.3.0`, март 2026)** — актуальная развиваемая ветка SDK (после обратного переименования из `@telegram-apps/*`), нативно поддерживает React 19 (`peerDependencies: react ^19.2.0`), Signals (`@tma.js/signals`) и методы Telegram Bot API вплоть до 9.x (`deviceStorage`, `viewport.requestFullscreen`, `safeAreaInset`, `contentSafeAreaInset`, `shareMessage`, `addToHomeScreen`, `secondaryButton`).
- **`@telegram-apps/sdk-react` (`3.3.9`, август 2025)** — замороженная предыдущая линейка пакетов.
- **Решение:** установлен `@tma.js/sdk-react@^3.0.23`, изолированный в FSD-слое `apps/web/src/shared/telegram` (ADR 0003).

### 2. Почему мы НЕ используем `@telegram-apps/telegram-ui`

- Пакет `@telegram-apps/telegram-ui@2.1.13` не обновлялся с апреля 2025 года, жёстко привязан к `react: ^18.0.0` (конфликтует с React 19 в монорепозитории) и навязывает системный iOS/Material-виджетный кит, который разрушает утверждённую дизайн-систему «Зин» (`docs/design/README.md`: бумага `#F6F1E7`, тушь `#141413`, сигнал `#FF4D1C`, гротеск `Dela Gothic One` + `Onest` + `Martian Mono`).
- Вместо стороннего UI-кита мы используем:
  1. Собственные примитивы «Зин» из `apps/web/src/shared/ui` (единый визуальный язык в TMA и в обычном браузере).
  2. Нативный хост-хром Telegram через `@tma.js/sdk-react` (`BackButton`, `MainButton`, `SecondaryButton`, `HapticFeedback`, `SwipeBehavior`, `Viewport` fullscreen и safe-area), когда приложение запущено внутри Telegram.

### 3. Архитектура Dual-Head Single-Build SPA (ТМА + обычный веб)

- Сайт обязан полноценно работать как внутри Telegram Mini App, так и в обычном мобильном/десктопном браузере по прямой HTTPS-ссылке (например, когда друг без Telegram или без VPN открывает шорт-лист `/s/<shareToken>`).
- При старте `initTelegramRuntime()` проверяет `isTMA()` из `@tma.js/sdk-react`. При наличии query-параметра `?tma=1` (или `VITE_TMA_MOCK=true`) автоматически поднимается `mockTelegramEnv` с перехватом событий WebApp — это позволяет разрабатывать и гонять Playwright e2e-тесты TMA-режима в обычном Chromium без клиента Telegram.
- Все вызовы компонентов SDK защищены проверкой `runtime.isTma` и `.ifAvailable()`, поэтому вне Telegram не происходит обращений к `window.Telegram.WebApp` и не кэшируется ложное состояние сигналов SDK.

### 4. Deep linking (`start_param` / `tgWebAppStartParam`) и маршрутизация

Функция `parseTelegramStartParam` транслирует параметр запуска `t.me/<bot>/<app>?startapp=...` в маршруты React Router при старте приложения:

- `s_<token>` или `shortlist_<token>` → `/s/<token>` (подборка друга «На вечер», US7/US8);
- `place_<id>` или `p_<id>` → `/place/<id>` (карточка места, US6);
- `add` → `/add` (экран приёма ссылки, US1);
- `evening` → `/evening` (авторский шорт-лист «На вечер», US7);
- `settings` → `/settings`.

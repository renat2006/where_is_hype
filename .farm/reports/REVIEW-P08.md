### Замечания

#### P2 (рекомендации, не блокируют)

1. **Ошибка сохранения не использует `ErrorNote`** — `saveError` отображается как `<span className="text-sm text-ink-muted">` ([candidate-list-view.tsx:86](file:///home/renat-ubuntu/dev/where_is_hype/.farm/worktrees/REVIEW-P08/apps/web/src/features/resolve-link/ui/candidate-list-view.tsx#L86), [search-place-view.tsx:133](file:///home/renat-ubuntu/dev/where_is_hype/.farm/worktrees/REVIEW-P08/apps/web/src/features/search-place/ui/search-place-view.tsx#L133)). По дизайн-системе «Зин» ошибки показываются через `ErrorNote` (`error-note` / `role="alert"` с иконкой на `note-bg`). Ошибка в `text-ink-muted` слишком незаметна — пользователь может не заметить «Не сохранилось. Попробуй ещё раз.»

2. **FSD: хуки и бизнес-логика в `ui/` сегменте** — `resolve-link-flow.ts` (207 строк бизнес-логики, хук, константы, утилиты) и `search-place-flow.ts` (95 строк) лежат в `ui/`. По FSD (ADR 0002) хуки и логика → `model/`, UI → `ui/`. Работает и lint проходит, но при росте кодовой базы будет путаница. Рекомендую перенести в `model/` в будущем.

3. **`fallbackQueryClient` — модульный синглтон** — ([add-place-page.tsx:25-36](file:///home/renat-ubuntu/dev/where_is_hype/.farm/worktrees/REVIEW-P08/apps/web/src/pages/add-place/ui/add-place-page.tsx#L25-L36)) создан как workaround для теста `router.test.tsx`. Это приемлемо для прототипа, но кеш может утечь между монтированиями. В продакшне лучше исправить тест, чтобы он оборачивал роутер в `QueryClientProvider`.

4. **Кнопка «Вставить ссылку» — не совсем точный текст** — На экране ввода ссылки кнопка `btn-primary` гласит «Вставить ссылку», хотя действие — «отправить/распознать». В задаче написано «поле ссылки», кнопка не специфицирована. Текст неплохой для MVP, но «Распознать» или «Найти место» может быть яснее.

5. **Заголовок `h1` отсутствует на экранах кроме `input`** — На шагах `loading`, `candidates` и `search` заголовок `<h1>` не рендерится (он внутри `step === 'input'`). Это не критично для экранов-подшагов, но может быть неудобно для screen readers. Рекомендую добавить скрытый `<h1 className="sr-only">` для всех шагов.

## Замечания

### P2: Не импортирован CSS MapLibre GL

**Файл**: `apps/web/src/widgets/places-map/ui/places-map.tsx`
**Строка**: отсутствует `import 'maplibre-gl/dist/maplibre-gl.css'`
**Описание**: MapLibre GL JS требует CSS для корректного отображения контейнера карты (`.maplibregl-map`, `.maplibregl-canvas`). Без CSS контейнер может не получить правильных размеров и позиционирования. Автор частично компенсирует это SVG-подложкой (`opacity-85` поверх) и жёстким позиционированием (`absolute inset-0`), но для полноценной работы MapLibre CSS необходим.
**Рекомендация**: Добавить `import 'maplibre-gl/dist/maplibre-gl.css'` в `places-map.tsx` или глобально в `app/styles`.

### P2: Radiogroup без клавиатурной навигации стрелками

**Файл**: `apps/web/src/features/geo-origin/ui/geo-origin-picker.tsx`
**Строки**: 88–124
**Описание**: Используется `role="radiogroup"` с `role="radio"` кнопками, но не реализована навигация стрелками (ArrowUp/ArrowDown) с roving tabindex. По WAI-ARIA Radio Group Pattern внутри группы должна работать навигация стрелками, а через Tab — только вход/выход из группы. Сейчас каждый radio фокусируется через Tab, что работает, но не соответствует паттерну.
**Рекомендация**: Добавить `onKeyDown` с обработкой Arrow-keys и `tabIndex={isSelected ? 0 : -1}` на кнопки, либо заменить на `<input type="radio">` с label.

### P2: MetroStation не отображается на карте при mode='metro'

**Файл**: `apps/web/src/pages/my-places/ui/my-places-page.tsx`
**Строки**: 173–182
**Описание**: `PlacesMap` получает `origin` (координаты), но не `originMetroName`. Поэтому даже когда геолокация запрещена и выбрана станция метро, на карте отображается `MyLocationDot` вместо MetroStation с названием. По макету экрана 06 при mode='metro' на карте должна быть плашка метро (pill с «М» и названием станции).
**Рекомендация**: Передавать `originMetroName={metroStation?.name}` в `PlacesMap` и убрать `userLocation` (чтобы отрисовывалась метка метро, а не точка).

### P2: Отсутствует рукописная фраза «жми плюс» и стрелка на экране 07

**Файл**: `apps/web/src/pages/my-places/ui/my-places-page.tsx`
**Строки**: 246–283
**Описание**: По макету экрана 07 под текстом «Кинь ссылку на ролик…» есть рукописная фраза «жми плюс» (Caveat) и нарисованная стрелка к FAB-кнопке. В реализации они отсутствуют. По правилу «чище, чем на холсте» и «один акцент на экран» это допустимо, но макет их явно включает как единственный декоративный акцент пустого состояния.
**Рекомендация**: Можно добавить (Caveat фраза + arrow-hand ассет), но это не блокер — пустой экран понятен и без них.

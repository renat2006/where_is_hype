# 0001. Стек MVP

- Статус: Предложено
- Дата: 2026-10-26
- Обсуждение: [документ со сравнением вариантов](https://claude.ai/artifact/3YKSRNdmXW6c2UJLAZ6A5k)

## Контекст

Нужен MVP сценария «Мои места», который к КТ-3 открывается по ссылке у эксперта без установки (мок-данные допустимы), а дальше дорастает до настоящего продукта без переписывания. Команда маленькая: разработка на TypeScript и Python, ML на Python. Есть VPS с Docker и Caddy. Instagram в РФ заблокирован, аудитория 18–25 живёт в Telegram.

## Варианты

- A. Веб-клиент React + Vite + TypeScript (PWA и Telegram Mini App одним билдом), бэкенд FastAPI + Postgres/PostGIS, воркер на Python.
- B. Next.js фуллстек на TypeScript + Postgres.
- C. Expo (React Native) + Supabase.

## Решение

Предлагается A. Будет зафиксировано после обсуждения.

## Последствия

- К КТ-3 делается только `apps/web` на мок-данных и выкладывается статикой.
- Два языка и два деплоя, зато ML и разбор ссылок сразу на Python.
- Нативное приложение откладываем, пока веб не покажет возвраты (R7/R30).

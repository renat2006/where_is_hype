# Функционал первого MVP

Статус: предложено, ждёт подтверждения Рената. Полная версия с обоснованием: [документ «Где Хайп?»: функционал первого MVP](https://claude.ai/artifact/H3ioZvGpTx4Gxe8NvboDSu).

Первый MVP — не «карта хайпа», а путь «из сохранённого ролика до визита»: человек кидает ссылку на Reels или пост, место появляется на его карте, вечером он отбирает 2–3 открытых варианта, отправляет другу ссылкой и отмечает, что сходил.

Почему так: 31 из 39 опрошенных, кто сохранял место из ленты, так и не сходили туда; ручной перенос из Reels в карты занимает 15–20 минут (интервью); сами выбирают место только 16 из 52; боли «не знаю, что сейчас модно» нет ни в одном из 4 интервью.

Рамки: Москва внутри Садового кольца; кафе, кофейни, рестораны, бары (в кафе и кофейни ходят чаще, чем в бары: 28 из 70 бывают там 8+ раз в месяц, в барах 45 из 70 не были ни разу).

Данные: опрос (70 ответов, выгрузка от 26.10), 4 интервью, советы экспертов. В новых открытых ответах есть «нет свободных столиков» и «слишком много людей», это поддерживает P1 «тихо или шумно».

## Функции

| ID | Функция | Приоритет |
| --- | --- | --- |
| F1 | Добавить место по ссылке (Reels, TikTok, ВК, Telegram, любая) или по названию; модель только предлагает, место берётся из базы, человек подтверждает | P0 |
| F2 | Карта «Мои места»: все сохранённые на одной карте и списком, моя точка, расстояние | P0 |
| F3 | Карточка места: адрес, метро, часы и «открыто сейчас», тип, чек, исходный ролик, заметка; «Маршрут» и «Отзывы» ведут в Яндекс Карты | P0 |
| F4 | Фильтр «на вечер»: открыто в выбранный час, тип, чек, рядом с метро | P0 |
| F5 | Шорт-лист «На вечер» (2–5 мест) и ссылка другу: страница без установки, голос «Мне подходит» | P0 |
| F6 | Отметка «Я здесь» с проверкой геопозиции и вопросом «Совпало с ожиданиями?» | P0 |
| F7 | Без регистрации (анонимный профиль) и аналитика событий воронки | P0 |
| F8 | «Поделиться → Где Хайп?» из ленты (Android, установленное веб-приложение) | P1 |
| F9 | Несколько мест из одного ролика-подборки | P1 |
| F10 | Метки или папки | P1 |
| F11 | «Тихо / громко вечером» и «как найти вход» от посетивших | P1 |
| F12 | Вход через Яндекс ID или почту с переносом данных | P1 |
| F13 | Друг добавляет своё место в шорт-лист | P1 |
| F14 | «Обсуждают сейчас»: ручная подборка новых мест района | P2 |
| F15 | Прогулка по нескольким местам из шорт-листа | P2 |
| F16 | Напоминание о несходенных местах рядом | P2 |

Не делаем в первом MVP: хайп-индекс и тепловую карту, массовый парсинг соцсетей, поиск по фото, свайпы, свои отзывы и рейтинги, платное продвижение и кабинет заведения, QR на кассе, события и афишу, сценарии «поесть рядом сейчас» и «банкет», бронь, чат с ИИ, мини-приложение в мессенджере.

## Ключевой сценарий

Пятница, друг пишет «куда сегодня?». В сохранённых десяток мест, непонятно, какие рядом и открыты.

| Шаг | Действие | Ответ продукта | Развилка | US |
| --- | --- | --- | --- | --- |
| 1. Сохранить | Вставляет ссылку на ролик | До 3 кандидатов с адресом и метро, «Да, сохранить» | Не узнали → поиск по названию | US1, US2 |
| 2. Увидеть свои места | Открывает приложение | Карта «Мои места», список по расстоянию | Пусто → подсказка; гео запрещена → выбор метро | US3 |
| 3. Отобрать на вечер | «Открыто в 19:00», «бар», «до 1 500 ₽» | 3–5 мест на карте и в списке | Пусто → «Сбросить фильтры» | US4 |
| 4. Проверить | Открывает карточку | Часы, чек, ролик, заметка, «Отзывы в Яндекс Картах» | Не подходит → назад, фильтр сохранён | US5 |
| 5. Договориться | 2–3 места в «На вечер», «Отправить» | Системное «Поделиться»; друг голосует без установки | Друг молчит → можно идти без голоса | US6, US7 |
| 6. Добраться | «Маршрут» | Яндекс Карты с маршрутом | Нет приложения → веб | US5 |
| 7. Отметить визит | «Я здесь» | «Визит отмечен», вопрос об ожиданиях | Гео дальше 200 м → «без проверки» | US8 |

## User Stories P0

### US1. Добавить место по ссылке (F1)
Как человек, увидевший место в ролике, я хочу вставить ссылку и сохранить место, чтобы не искать его потом и не вбивать в карты руками.
- [ ] Принимает ссылки Instagram, TikTok, ВК, t.me, YouTube и любые другие.
- [ ] Если из описания удалось достать название, не позже чем через 5 с показаны до 3 кандидатов из базы мест с адресом и метро.
- [ ] Без «Да, сохранить» ничего не сохраняется; место всегда берётся из базы, а не из ответа модели.
- [ ] Не достали название или ссылка закрыта → сразу поиск US2, ссылка не теряется.
- [ ] Место хранит исходную ссылку и дату добавления.
- [ ] Повтор того же места → «Уже в твоих местах», без дубля.

### US2. Найти место по названию (F1)
Как пользователь, я хочу найти место по названию, чтобы сохранить его без ссылки.
- [ ] Подсказки со 2-го символа, ответ до 1 с.
- [ ] Только кафе, кофейни, рестораны, бары; места внутри Садового кольца выше.
- [ ] Ничего не нашли → «Не нашли место» и «Сообщить», заявка сохраняется для команды.

### US3. Карта «Мои места» (F2)
Как пользователь с десятком сохранений, я хочу видеть их на одной карте, чтобы понять, что рядом.
- [ ] Все сохранённые места метками, перекрывающиеся объединяются с числом.
- [ ] Под картой список по расстоянию.
- [ ] Геолокация запрашивается один раз; отказ → выбор станции метро как точки отсчёта.
- [ ] Пусто → «Кинь ссылку на ролик» и кнопка добавления.

### US4. Фильтр «на вечер» (F4)
Как пользователь, выбирающий на вечер, я хочу оставить только открытое, нужного типа и по карману, чтобы не проверять каждое место в картах.
- [ ] Фильтры: «открыто в» (сейчас или час сегодня), тип, чек «до N ₽», «рядом с метро» (до 1 км).
- [ ] Карта и список обновляются сразу, видно число найденных.
- [ ] Места с неизвестными часами или чеком не скрываются, а помечаются «не уточнено».
- [ ] Пусто → «Ничего не подошло» и «Сбросить фильтры».
- [ ] Фильтр сохраняется при переходе в карточку и обратно.

### US5. Карточка места и маршрут (F3)
Как пользователь, я хочу быстро проверить место и построить маршрут, чтобы решить и добраться.
- [ ] Название, тип, адрес, метро, «Открыто до 23:00» / «Закрыто, откроется в 12:00» / «Часы не уточнены», чек, исходный ролик, заметка до 280 символов.
- [ ] «Маршрут» открывает Яндекс Карты с маршрутом до точки (приложение, иначе веб).
- [ ] «Отзывы» открывает организацию в Яндекс Картах или поиск по названию и адресу.
- [ ] Удаление места с отменой в течение 5 с.

### US6. Шорт-лист и ссылка другу (F5)
Как тот, кто предлагает варианты, я хочу собрать 2–5 мест и отправить другу одной ссылкой, чтобы договориться без долгой переписки.
- [ ] Место добавляется в «На вечер» из карточки и списка, лимит 5.
- [ ] «Отправить» открывает системное «Поделиться», где его нет — копирует ссылку.
- [ ] В мессенджере у ссылки превью с названиями мест.
- [ ] Ссылка работает 7 дней.

### US7. Друг голосует по ссылке (F5)
Как друг, получивший ссылку, я хочу без установки увидеть варианты и отметить подходящий, чтобы быстро ответить.
- [ ] Открывается без входа и установки, первый экран до 3 с на 4G.
- [ ] Карта и мини-карточки мест: адрес, метро, часы, чек, ссылка на ролик.
- [ ] «Мне подходит» на одном или нескольких местах, имя необязательно; повторный голос из того же браузера меняет, а не добавляет.
- [ ] Автор видит голоса в своём шорт-листе.
- [ ] Внизу ненавязчивое «Собирай свои места».

### US8. Отметка визита (F6)
Как пользователь, я хочу отметить, что сходил, чтобы место перешло в «Был здесь».
- [ ] «Я здесь» в карточке сохранённого места.
- [ ] Гео в пределах 200 м → «подтверждён», иначе «без проверки»; в аналитике раздельно.
- [ ] Не больше одного визита в место за день.
- [ ] После отметки «Совпало с ожиданиями?»: лучше / как ждал / хуже, плюс необязательный текст.
- [ ] На следующий день после отправки шорт-листа при открытии — «Сходили вчера?».

### US9. Старт без регистрации (F7)
Как новый пользователь, я хочу начать без регистрации, чтобы сразу добавить первое место.
- [ ] При первом запуске создаётся анонимный профиль, данные на сервере.
- [ ] Знакомство не длиннее 2 экранов и заканчивается полем для ссылки.
- [ ] Не собираем имя, телефон и почту.

### US10. Аналитика воронки (F7)
Как команда, мы хотим видеть воронку от ссылки до визита, чтобы проверить гипотезу MVP.
- [ ] События: `link_pasted`, `candidates_shown`, `place_saved` (link / name), `map_opened`, `filter_applied`, `card_opened`, `route_clicked`, `shortlist_shared`, `friend_page_opened`, `friend_voted`, `visit_marked` (verified / not), `expectation_answered`.
- [ ] У каждого события анонимный id и время, без персональных данных.
- [ ] Воронка и R7/R30 считаются одним запросом или в Яндекс Метрике.

## Нефункциональные требования

- Мобильный Chrome и Safari, последние 2 версии; экраны сначала под ширину 360 px; интерфейс на русском.
- Устанавливается как веб-приложение; список мест открывается без сети из кэша.
- Из роликов храним только ссылку и текст описания, не видео.

## Гипотеза MVP

Из тех, кто добавил 3+ места, не менее 30% за 14 дней отметят визит хотя бы в одно из них (сейчас до места из ленты доходят 11 из 64, 17%). Промежуточные цели: активация 40%, подтверждение первого кандидата 70%, отправка шорт-листа 30% активированных, голос друга в 50% открытых ссылок. Это наши цели, а не данные.

Все e2e-сценарии веб-приложения (`apps/web/e2e/scenarios.spec.ts` и `apps/web/e2e/funnel.spec.ts`) запускаются на моках (`VITE_API_MOCKS=true`) в мобильном разрешении `360×780` на выделенном порту `4704` одной командой из корня репозитория:

```bash
PORT=4704 pnpm --filter @where-is-hype/web test:e2e
```

Для запуска только матрицы сценариев `K4-P1`:

```bash
PORT=4704 pnpm --filter @where-is-hype/web exec playwright test e2e/scenarios.spec.ts
```

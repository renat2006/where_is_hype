## Главное правило: стиль помогает контенту

Ренат утвердил стиль, но местами макеты получились перегруженными. В коде делаем чище, чем на холсте: стилизация дополняет контент и не мешает его читать. Это правило важнее отдельных декоративных деталей из макетов; если они спорят, побеждает чистота.

1. **Контент первым.** На любом экране первыми читаются название места, статус часов и расстояние. Декор не перекрывает и не оттягивает на себя внимание от них.
2. **Один акцент на экран.** Сверх наклеек-меток на экране не больше одного декоративного элемента: маркерная обводка, рукописная фраза Caveat, стрелка, скотч или зачёркивание. Если на экране уже есть рукописная фраза, обводку не добавляем.
3. **Списки и формы спокойные.** Строки списка, поля, фильтры, кнопки, ошибки, тосты и навигация без поворотов, скотча и рукописного текста. Строки списка плоские, разделены линией `line`, без обводки и тени у каждой строки.
4. **Рамки и тени по делу.** Обводка 1,5 px `ink` только у интерактивных элементов и одного главного контейнера экрана. Тень `raised` только у главной кнопки и наклеек. Вложенные рамки внутри рамок не делаем.
5. **Одна главная кнопка.** `btn-primary` максимум одна на экран, остальное `btn-secondary` или `btn-text`.
6. **Типографика сдержанно.** Dela Gothic One только для заголовка экрана и названия места в карточке, от 20 px. На экране не больше двух размеров заголовков. Цифры (время, расстояние, чек, голоса) моноширинным `font-mono`.
7. **Воздух.** Поля экрана 16 px, между блоками 16–24 px, касание не меньше 44×44. Плотнее не собираем, даже если на холсте плотнее.
8. **Зерно бумаги выключено** по умолчанию (флаг остаётся в токенах).
9. **Движение только из токенов** (`motion-*`), без зацикленных анимаций; при `prefers-reduced-motion` только смена прозрачности.
10. **Проверка глазами.** Перед сдачей задачи с UI посмотри экран в ширине 360 px в дневной и ночной теме и задай себе вопрос: «Что здесь можно убрать, не потеряв смысла?» Если что-то можно убрать, убери.

Ревьюер проверяет эти пункты: нарушение правил 1–6 считается P1.

## Токены

Цвета, шрифты, радиусы и тень заданы в [`zin/Rules.dc.html`](zin/Rules.dc.html) (блок «Токены в коде · Tailwind 4») и подробно в [`zin/Main.dc.html`](zin/Main.dc.html). В коде они живут в `apps/web/src/app/styles` как `@theme` Tailwind 4 с ночной темой через `[data-theme="night"]`. Новый цвет появляется только как новый токен в обеих темах.

- Шрифты: Dela Gothic One (заголовки), Onest 400/500/600/700 (интерфейс, база 16 px), Caveat 600 (одна рукописная фраза на экран), Martian Mono (цифры). Подключаем локально woff2 с латиницей и кириллицей.
- Сетка 4 px: `space-1…12` = 4, 8, 12, 16, 24, 32, 48. Радиусы: 8, 16, 24, 999.
- Тема: «Авто» по закату в Москве, вручную День или Ночь в настройках.
- Карта: MapLibre + OpenFreeMap со своим стилем слоёв `map-*` из `Main.dc.html`.

## 10 запретов (из холста)

1. Белый текст на маркере. На `marker` только `on-marker`.
2. Больше одной рукописной фразы на экран; Caveat в кнопках, ошибках, ценах и часах.
3. Свои обводки, зачёркивания, стрелки и скотч: только готовые ассеты `marker-oval-1..3`, `strike`, `arrow-hand`, `tape`.
4. Смысл только цветом: у статуса всегда есть текст или иконка.
5. Цвета вне токенов.
6. Красный для ошибок: ошибка = `ink` + иконка + текст на `note-bg`.
7. Мягкие размытые тени: только `raised`.
8. Цифры не моноширинным шрифтом.
9. Dela Gothic One меньше 20 px и для длинного текста.
10. Хайп-индекс, рейтинги, отзывы, свайпы и ленты: их нет в MVP. Места с неизвестными часами или чеком не прячем, а помечаем «не уточнено».

## Какой компонент для какой задачи

| Задача                            | Компонент                             |
| --------------------------------- | ------------------------------------- |
| Главное действие экрана (одно)    | `btn-primary`                         |
| Внешние переходы: маршрут, отзывы | `btn-secondary`, ссылка ↗             |
| Сброс, отмена, «Не то»            | `btn-text`                            |
| Кнопка поверх карты               | `btn-map`                             |
| Тип, час, чек в фильтре           | `chip`, `hour-picker`, `price-picker` |
| Место на карте                    | `sticker-{type}-{state}`, `cluster`   |
| Место в списке                    | `place-row`                           |
| Результат распознавания ролика    | `candidate-card`                      |
| Открыто / закрыто / не уточнено   | `hours-status`                        |
| Голос друга                       | `vote` + `avatars`                    |
| Удаление с отменой                | `toast` (5 с)                         |
| Ошибка / нет сети                 | `error-note`, `offline-banner`        |
| Список под картой                 | `sheet`: peek 96 / half 50% / full    |

Иконки: Lucide, линия 2 px.

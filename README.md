# «Где Хайп?»

Приложение, которое собирает места, сохранённые из Reels и постов, на одной карте, помогает выбрать с другом, куда пойти, и подтверждает визит.

Старт: Москва, район Покровки. Ключевой сценарий MVP «Мои места»:

1. Вставить ссылку на Reels или пост (или поделиться ей из Instagram через системное меню телефона).
2. Подтвердить, какое это место, и увидеть его на карте рядом с другими сохранёнными.
3. Выбрать 2–3 варианта и отправить другу, друг голосует по ссылке без регистрации.
4. Построить маршрут и подтвердить визит (QR на месте или код вручную).

## Статус

## Как работаем

- `main` всегда рабочий. Прямо в него не пушим, всё через pull request.
- Ветка на задачу: `feat/...`, `fix/...`, `chore/...`, `docs/...`.
- Коммиты короткие, по-русски или по-английски, в повелительном наклонении: «Добавить карту мест».
- PR небольшой, с описанием по шаблону и ссылкой на задачу. Мержим после зелёного CI и одного ревью.
- Задачи заводим из шаблонов: «Пользовательская история» (с ID вида US1 и критериями приёмки) или «Баг».
- Секреты только в `.env` (он в `.gitignore`), в репо кладём `.env.example`.
- Персональные данные из опросов и интервью (контакты, ники) в репо не кладём.
- Важные технические решения записываем в `docs/decisions/` коротким ADR.

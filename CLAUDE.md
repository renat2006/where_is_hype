# CLAUDE.md

Контекст для Claude и других ИИ-ассистентов, работающих с этим репозиторием.

## Проект

«Где Хайп?»: места, сохранённые из Reels и постов, на одной карте; выбор с другом из 2–3 вариантов; подтверждённый визит. Москва, старт с Покровки. Подробнее в [README](README.md).

Пишем название так: «Где Хайп?» (с вопросительным знаком, в кавычках-ёлочках в тексте).

## Язык

- Общение, документация, тексты интерфейса, описания PR и задач: по-русски.
- Код, идентификаторы, имена файлов: по-английски.
- Тексты интерфейса короткие: заголовок + одна строка пояснения. Без канцелярита.

## Что входит в MVP, а что нет

Входит: вставка ссылки из Reels/поста → подтверждение места → карта «Мои места» → карточка места (громко/тихо, фото входа) → отправка другу 2–3 вариантов → голос друга → маршрут через Яндекс Карты → подтверждение визита (QR или код).

Не входит, пока явно не попросят: кабинет для заведений, массовый парсинг соцсетей, поиск по фото, свайпы, регистрация по паролю, свой построитель маршрутов.

## Правила

- Изменения только через PR в `main`, шаблон PR заполнять.
- Не коммитить секреты, `.env`, выгрузки опросов и интервью, контакты людей.
- Перед PR прогнать линтеры и тесты из CI локально.
- Новое техническое решение, которое трудно откатить, оформлять ADR в `docs/decisions/`.
- Стек: см. `docs/decisions/0001-stack.md`. Пока статус «Предложено», каркас приложений не создавать.

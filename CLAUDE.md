Контекст для Claude и других ИИ-ассистентов в этом репозитории. Правила команды: [CONTRIBUTING.md](CONTRIBUTING.md), стек и команды: [README.md](README.md).

## Проект

«Где Хайп?»: места, сохранённые из Reels и постов, на одной карте; выбор с другом из 2–3 вариантов; подтверждённый визит. Москва, старт с Покровки. В тексте название пишем «Где Хайп?» (с вопросительным знаком, в ёлочках).

## Язык

- Общение, документация, тексты интерфейса, описания PR и задач: по-русски.
- Код, идентификаторы, имена файлов, сообщения об ошибках в коде: по-английски.

## Рамки MVP

Входит: вставка ссылки из Reels/поста → подтверждение места → карта «Мои места» → карточка места (громко/тихо, фото входа) → отправка другу 2–3 вариантов → голос друга → маршрут через Яндекс Карты → подтверждение визита (QR или код).

Не входит, пока явно не попросят: кабинет для заведений, массовый парсинг соцсетей, поиск по фото, свайпы, регистрация по паролю, свой построитель маршрутов, Telegram Mini App (Telegram заблокирован в РФ).

## Как писать код

- Перед PR: `pnpm check` в корне и `uv run ruff check . && uv run ruff format --check . && uv run mypy src tests && uv run pytest` в `apps/api`.
- `apps/web` строго по FSD (ADR 0002). Новый код кладём в слой по смыслу, импорт только вниз через `index.ts` слайса и алиас `@/`. Относительные импорты только внутри слайса.
- Доменные типы и схемы, которые понадобятся другим клиентам, живут в `packages/core`, а не в `apps/web`.
- Запросы к API через `apiGet` из `@/shared/api` со схемой Zod и `queryOptions` из TanStack Query в сегменте `api` сущности или фичи.
- Моки API в `apps/web/src/shared/api/mocks`, включаются `VITE_API_MOCKS=true`.
- Без лишних комментариев, `any`, неиспользуемого кода и зависимостей «на всякий случай».
- Новое трудно откатываемое решение оформляем ADR в `docs/decisions/`.
- Не коммитить секреты, `.env`, выгрузки опросов и интервью, контакты людей.
